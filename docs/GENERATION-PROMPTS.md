# Generation Prompt Record

Built-in image generation was used. Ava established the master visual system; each later portrait used the completed set as visual references.

## Shared system

Polished warm modern 3D animated-feature character art; rounded forms; subtle skin translucency; large kind expressive eyes with soft catchlights; square head-and-shoulders; exactly front-facing; centered; generous headroom; even soft frontal studio light; minimal lower-face shadow; gentle closed-mouth smile; simple circular accent-color backdrop on warm off-white; no text, logo, watermark, open mouth, teeth, hand gestures, cropped hair, busy detail, uncanny realism, corporate clipart, or bobblehead proportions.

Keep lens, camera height, framing, eye scale, head proportions, lighting, shoulder crop, and backdrop geometry consistent. Change only identity, hair, skin tone, age, accent color, and personality.

## Important limitation

Prompting for a closed mouth improves downstream editability but does not create an actual mouth rig. Production overlays must be created and validated separately.
